# 📅 Day 17 – Threat Intelligence basics

Today I studied **Threat Intelligence basics** and created a quick cheat sheet.

---

## 📝 What I Learned
- **Threat Intelligence =** Actionable knowledge about cyber threats.
- **Data → Information → Intelligence:** Raw facts → Context → Actionable insight.
- **Types of Threat Intelligence:**
  - Strategic → Business impact
  - Tactical → TTPs (Tactics, Techniques, Procedures)
  - Operational → Campaigns
  - Technical → IOCs (Indicators of Compromise)
- **Threat Actors:** Cybercriminals, Nation‑States, Hacktivists, Insider Threats, Script Kiddies, Organized Crime Groups.
- **IOCs:** IPs, Domains, URLs, File Hashes, Email Indicators, Registry Keys, File Paths.
- **TTPs:**  
  - Tactics = Why  
  - Techniques = How  
  - Procedures = Exact steps  
- **IOC vs TTP:** IOCs change quickly; TTPs remain consistent.
- **Intelligence Lifecycle:** Direction → Collection → Processing → Analysis → Dissemination → Feedback.
- **SOC Focus:** IOC enrichment, threat hunting, alert validation, TTP‑based detection.

---

## 💡 Key Takeaways
- Threat Intelligence turns raw data into **actionable insights**.
- SOC analysts rely on both **IOCs** and **TTPs** for detection and hunting.
- Understanding the lifecycle helps structure intelligence work.

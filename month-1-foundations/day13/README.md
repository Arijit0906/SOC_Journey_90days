# 📅 Day 13 – Poweshell deep-dive
Today I focused on **PowerShell** and its important commands for SOC engineers.

---

## 📝 What I Learned
- Core commands:
  - `Get-Process` → View running processes
  - `Get-Service` → Check services
  - `Get-EventLog` / `Get-WinEvent` → Read event logs
  - `Get-Content` → Read files
  - `Select-String` → Search inside files
  - `Invoke-WebRequest` → Download or interact with web resources
- Pipelines (`|`) make filtering and analysis powerful.
- Attackers often abuse PowerShell, so monitoring usage is critical.

---

## 💡 Key Takeaways
- PowerShell is essential for both defenders and attackers.
- Knowing the basics helps SOC engineers investigate suspicious activity quickly.

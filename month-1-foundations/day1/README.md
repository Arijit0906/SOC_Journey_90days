# 📅 Day 19 – SOC Analyst 30-Day Challenge

Today I studied **Incident Response (IR) Fundamentals** — the core responsibility of every SOC Analyst.

---

## 📝 What I Learned

### 🔹 Module 1: Introduction to IR
- What Incident Response is
- Security Event vs Security Incident
- Importance & goals of an IR program

### 🔹 Module 2: IR Lifecycle
- Preparation → Identification → Containment → Eradication → Recovery → Lessons Learned

### 🔹 Module 3: Classification & Prioritization
- Severity levels (Low, Medium, High, Critical)
- Categorization
- Impact vs Urgency
- Escalation process

### 🔹 Module 4: Detection & Analysis
- Sources: SIEM alerts, EDR/XDR, Threat Intelligence, Log Analysis

### 🔹 Module 5: Containment Strategies
- Short‑term vs Long‑term containment
- Host isolation, account disablement, network segmentation

### 🔹 Module 6: Eradication & Recovery
- Malware removal, vulnerability patching, system restoration, recovery validation

### 🔹 Module 7: Documentation & Reporting
- Incident timeline creation
- Evidence collection & chain of custody basics
- Writing incident reports

### 🔹 Module 8: Common Security Incidents
- Phishing, Malware/Ransomware, Brute Force, Insider Threats, Data Exfiltration

### 🔹 Module 9: SOC Analyst Role
- Alert triage, investigation workflow, escalation to L2/L3, communication during incidents

### 🔹 Module 10: Practical Labs
- IR scenarios, investigation walkthroughs, SOC interview questions
- Mini Incident Response case study

---

## 💡 Key Takeaways
- IR is about **detecting, investigating, containing, eradicating, recovering, and documenting** cyber incidents.
- SOC analysts play a central role in triage, investigation, and communication during incidents.
